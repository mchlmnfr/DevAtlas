# Generated regression logs

`tests/run-quality.py` writes per-suite logs here. They are generated output and
are ignored by Git; run the suites to produce logs for your own installation.

The committed JSON summaries in the parent directory are historical checkpoints,
not proof that the current checkout passed. Their `validation/*.log` entries
identify generated output paths; the old workstation logs are no longer shipped.
Manual QMS reviews, audit baselines, migration evidence and route manifests remain
under version control.
